# Project Overview

TreeSize Free is a Windows disk space analyzer designed to show how storage is being used by files and folders. It provides a hierarchical directory view, file and folder sizes, graphical storage visualization, and tools for identifying large areas of disk usage.

TreeSize Free is the freeware edition of TreeSize from JAM Software and is intended for personal and general desktop storage analysis. It can scan internal drives as well as supported external and removable storage.

The current Free release is **TreeSize Free 4.8.1**. The official changelog lists version 4.8.1 as the latest Free release.

---

# Disk Space Analysis

TreeSize Free scans selected drives and folders and presents their storage usage in an organized hierarchical structure.

The directory tree makes it possible to identify large folders and navigate through nested directories without manually checking each folder in Windows Explorer.

The application can display information such as file count, folder size, allocated space, and other available details.

TreeSize Free also supports scanning NTFS and exFAT storage, including USB drives, SD cards, external HDDs, and SSDs.

---

# Treemap Visualization

TreeSize Free provides a treemap visualization that represents disk usage graphically.

Larger areas correspond to files or folders consuming more storage space, allowing storage-heavy content to be identified quickly.

The current Free version uses the treemap as a default visualization of disk space allocation.

This view can be especially useful when analyzing large drives where a traditional folder tree alone may require considerable navigation.

---

# File Search & Reports

TreeSize Free provides file and folder information directly within its results interface.

The application can create PDF reports of disk space usage and export information based on the available columns and views.

Search and filtering functions can help narrow down the displayed content and make it easier to investigate specific folders or files.

---

# Windows Explorer Integration

TreeSize Free integrates with Windows File Explorer through a context-menu entry.

The current version restores the ability to launch TreeSize Free directly from the context menu for drives, allowing users to analyze disk usage without first opening the application separately.

Version 4.8 also added support for accessing TreeSize Free from the Windows 11 File Explorer context menu.

# System Compatibility & Performance

| ---------------- | ---------------------------------------- |
| Operating System | Windows 10 / Windows 11                  |
| Processor        | Modern dual-core CPU                     |
| Memory           | 1 GB RAM minimum; 2 GB+ recommended      |
| Storage          | Approximately 100 MB for the application |
| Graphics         | Integrated graphics supported            |
| Display          | 1024×768 or higher                       |
| Architecture     | 64-bit Windows                           |
| File Systems     | NTFS / exFAT                             |
| Internet         | Not required for local disk analysis     |

TreeSize Free is designed to remain relatively lightweight, although scanning performance depends on drive speed, number of files, directory structure, and storage capacity.

The current Free version is intended for modern Windows desktop systems. Windows Server operating systems are not supported by TreeSize Free.
